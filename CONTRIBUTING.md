# Contributing

Thanks for helping make The Hotel Media better.

The Hotel Media is **closed source**. This repository holds the README, the changelog and the community spaces, but not the app's code. That means the most useful things you can send are bug reports and ideas.

## Report a bug

1. Make sure you're on the latest version from the [App Store](https://apps.apple.com/in/app/the-hotel-media/id6670192036) or [Google Play](https://play.google.com/store/apps/details?id=com.thehotelmedia.android).
2. Search the [open issues](https://github.com/soensingh/the-hotel-media/issues) in case someone already reported it. If they did, add a thumbs-up reaction or any new details there.
3. Open a [bug report](https://github.com/soensingh/the-hotel-media/issues/new?template=bug_report.yml) and fill in the form. The most helpful details:
   - the app version, iOS or Android, your OS version and your phone model;
   - which part of the app it happened in (feed, bookings, food orders, events, chats, and so on);
   - exact steps, what you expected and what happened;
   - a screenshot or short screen recording.

## Suggest an idea

Post it in [Discussions → Ideas](https://github.com/soensingh/the-hotel-media/discussions/categories/ideas). Upvote the ideas you'd like to see, too.

## Ask a question

Use [Discussions → Q&A](https://github.com/soensingh/the-hotel-media/discussions/categories/q-a).

## Payments, bookings, orders and account problems

Email **support@thehotelmedia.com**. Please **never post phone numbers, OTPs, payment IDs, booking or order details** in issues or discussions. Anyone can read them.

## Security problems

Report them privately as described in [SECURITY.md](SECURITY.md).

## Pull requests

Because the code isn't here, pull requests are limited to **documentation fixes**: typos, broken links and unclear wording in this repo's Markdown files. Please open an issue first for anything bigger.

By sending a pull request you agree that it can be used as described in [LICENSE](LICENSE), section 5.

## Be kind

Everyone taking part here is expected to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
